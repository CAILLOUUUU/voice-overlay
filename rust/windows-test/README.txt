Voice Overlay (Rust) - Windows test

1. Right-click the zip > Properties > tick "Unblock" > OK, then extract it.
2. Open the Discord desktop app (and League if you want to test roles).
3. Double-click RUN-TEST.bat and follow the questions (about 2 minutes).
   If Windows says "Windows protected your PC": More info > Run anyway (the exe is not signed yet).
4. Send back voice-overlay-test-report.zip from your Desktop.

Your normal Voice Overlay is not touched: the test uses a copy of your settings,
runs on port 47480, restores your "start with Windows" setting and cleans up after itself.
