Connexion à Discord (une seule fois)

  1. Ouvre le portail développeur Discord et clique sur New Application (le nom n'a pas d'importance).
  2. Dans OAuth2, ajoute http://localhost dans Redirects, puis Save Changes.
  3. Toujours dans OAuth2, copie le Client ID, puis clique sur Reset Secret et copie le Client Secret.
  4. Colle les deux ci-dessous. Ils restent sur ton PC, dans config.json.
